大水理论最严厉的母亲 · Windows x64 试用版 0.1.0-preview

把妈妈请进电脑，催你喝水、起身，也惦记你有没有吃饭。

1. 将整个 ZIP 解压到你有写入权限的文件夹，例如“下载”或“文档”。
2. 双击“1-先看演示.cmd”，启动后会展示三个场景，随后进入正常提醒。
3. 双击“2-打开设置.cmd”，可以调整妈妈形象、发色、语言，点击气泡改台词。
4. 日后直接运行 大水理论最严厉的母亲.exe。托盘里出现粉色小水杯表示正在运行。
5. 右键托盘图标可以暂停、演示、设置、开关自启或退出。
6. 退出也可以双击“3-退出程序.cmd”。

无需安装 Python；不需要管理员权限。请保留同一文件夹里的全部文件。
这是未签名的试用版。若 Windows 显示来源警告，请先核对下载来源与 SHA256SUMS.txt；不要关闭系统保护。

程序只在你主动开启“开机自启”时写当前用户的自启项。
配置、日志、状态和立绘缓存在本文件夹生成。无需登录，不上传数据。
退出并取消自启后，删除整个文件夹即可卸载。

默认每次闪现约 2 秒，任意两次正常提醒至少间隔 20 分钟。
首次演示是主动预览，不代表平时的提醒频率。
若台词读不完，可以编辑 config.toml，将对应场景 show_s 调大。
会议、全屏和勿扰信号可能受 Windows 版本与应用行为影响。

本包已做离屏渲染与打包检查；不等于所有 Windows 设备均完成实机验收。
故障请查看 logs/launcher-error.log 或 logs/app.log。
